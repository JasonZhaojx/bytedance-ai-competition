# 3款主流竞品全维度画像
## 1. 通义灵码（Qoder CN）
- 定位：阿里云生态绑定的企业级AI编码辅助工具
- 优势：背靠阿里云品牌背书，政企采购渠道成熟，2026年7月将实现QoderWork CN与Credits互通形成办公+编码场景闭环
- 劣势：2026年企业版涨幅最高达152%，中小团队采购成本大幅提升，存在插件兼容、IDE冲突故障
- 缺失字段：全量第三方插件兼容规则、SSO/SOC2合规官方公开说明
- PM implication：可主打中小团队高性价比差异化定位，避开阿里云政企核心赛道
## 2. CodeGeeX
- 定位：高校背景开源导向的免费AI编码工具
- 优势：100万+个人用户基础，全功能免费无硬调用限制，开源9B模型支持本地离线部署，用户粘性高
- 劣势：商业化信息完全不透明，无公开付费档位与企业服务说明，变现路径模糊
- 缺失字段：全档位订阅定价体系、企业版服务能力、SSO/SOC2合规资质、接入大模型完整清单
- PM implication：可对标其免费特性做个人版权益升级，抢占其未覆盖的付费企业用户市场
## 3. 腾讯云CodeBuddy
- 定位：腾讯云生态绑定的AI编码辅助工具，侧重微信开发生态
- 优势：腾讯云品牌背书，微信生态适配深度高，政企采购渠道成熟
- 劣势：2026年企业版涨幅超150%，免费版额度耗尽后响应延迟极高，高频调用易受限
- 缺失字段：全量合规资质、官方标准化提效量化数据
- PM implication：可主打无云厂商中立定位，吸引反感云生态强绑定的开发者用户
